# Pluto Dataset

Dataset da biblioteca Pluto: questões, temas de redação, imagens e metadados.

- Versão: 2026.10.04
- Questões: 121831 · Redações: 2983 · Imagens: 1813
- Banco: 283 MiB (SHA-256 em `database/pluto.db.sha256`)

## Onde está o banco

O `pluto.db` passa do limite de 100 MiB por arquivo do Git, então é publicado como arquivo da
Release mais recente: https://github.com/Ykll27/pluto-dataset/releases/latest/download/pluto.db

As imagens ficam neste repositório, em `assets/` e `thumbnails/`; `database/manifest.json` descreve
a versão, as contagens e as fontes.

## Fontes e licenças

Consulte `database/manifest.json`, `LICENCAS.md` e `DATASET_POLICY.md`. Fontes com
`licenca_verificada = 0` não têm redistribuição confirmada.
