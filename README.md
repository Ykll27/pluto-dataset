# Pluto Dataset

Dataset da biblioteca Pluto com questões do ENEM, imagens, miniaturas e metadados.

- Arquivos: 5441
- Tamanho aproximado: 65.93 MiB
- Fonte: enem.dev

O arquivo `database/pluto.db` contém questões, alternativas, gabaritos e vínculos
com as imagens. Os arquivos de imagem são distribuídos nas pastas `assets`,
`thumbnails` e `metadata`.

> Não inclua tokens, senhas ou chaves neste repositório. Verifique as permissões
> de redistribuição do conteúdo antes de tornar o repositório público.
